Auto Attack Skill Set

Choose a saved preset or build your own rotation. Skills run in order and repeat.

1. Choose a preset

Choosing a preset applies it immediately. To save a copy, enter a new preset name.

2. Build your rotation

Add a skill at the cursor, or select text in the rotation to replace it.

Advanced: conditions, cooldowns and waits

Insert at the cursor or replace selected steps. If uses the HP/MP controls above; Cooldown uses selected skills. Wait and cast waits until the selected skill is ready, then casts it. Wait for selected skill checks readiness without casting.

Syntax and behavior

1; if SH<=50 { 2;3 }; wait 500ms; await 2; 4; cooldown { 3 }

SH = my HP %, SM = my MP %. Block < and > are strict; <= and >= include equality. Legacy inline conditions keep inclusive comparisons. If is tested once on entry; its steps continue in order. Blocks cannot nest; no else. Without a selection, If inserts 1;2 and Cooldown inserts the selected skill.

Wait is 1–60000ms; await 1 waits for skill 1–4 and casts it; ready 1 only waits without casting. The old global wait marker still waits before normal casts. Cooldown skills are checked in rotating order between combo steps and during waits, cast only when available, never forced. At most one casts per gap; the main combo keeps its position and gets the next turn. A waiting main skill gets priority when it becomes ready.

Example: 1;2;3;4. Edits are remembered automatically for the next Auto Attack start. Use rotation now to apply them immediately.
